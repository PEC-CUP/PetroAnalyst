# Released Keyword Graph Assets

This directory includes repository-safe keyword-graph assets generated from the 977-paper petroleum literature corpus described in the manuscript.

Included graph families:
- `topic_keyword_graph/`
- `core_domain_term_graph/`

Included file types per graph:
- `keyword_graph.html`
- `keyword_graph.json`
- `keyword_nodes.csv`
- `keyword_edges.csv`

Files containing local absolute paths or expanded document-level keyword listings were intentionally excluded from the public release.
The published graph assets therefore support visualization and reuse without redistributing large amounts of source-document text or local-machine metadata.
